# Train in Intervals

Train in Intervals — интервальный таймер для тренировок на iPhone, iPad и Mac. Задайте время работы и отдыха, количество интервалов и время на подготовку. Один и тот же таймер подходит для табаты, ОФП, бокса и круговых тренировок с одинаковыми интервалами. Для тренировки не нужен аккаунт или интернет.

В пользовательском интерфейсе приложение называется **Train in Intervals**. Техническое имя Xcode-проекта — `BoxingTimer`; основной target и Swift-модуль называются `Main`.

## Возможности

- 1–15 рабочих интервалов длительностью от 10 секунд до 15 минут;
- подготовка и отдых от 0 до 5 минут;
- настройка времени с шагом 5 секунд;
- предупреждение за 10 или 30 секунд до конца рабочего интервала;
- пауза, продолжение и досрочное завершение с подтверждением;
- восстановление активной сессии по абсолютным временным границам;
- фоновые звуковые уведомления;
- Live Activity на iPhone и iPad с отображением состояния сессии и маркировкой устаревших данных;
- интерфейс на английском, русском, испанском (Латинская Америка), португальском (Бразилия) и немецком с адаптацией к ориентации и размеру окна;
- локальное сохранение последней конфигурации и активной сессии.

По умолчанию настроены 3 интервала по 3:00, отдых 1:00, подготовка 0:10 и предупреждение за 10 секунд до конца рабочего интервала.

## Требования

- macOS с Xcode 16 или новее;
- iOS или iPadOS 18.0 либо macOS 15.0 или новее для запуска приложения;
- [XcodeGen](https://github.com/yonaskolb/XcodeGen);
- [SwiftGen](https://github.com/SwiftGen/SwiftGen).

Инструменты генерации можно установить через Homebrew:

```sh
brew install xcodegen swiftgen
```

## Запуск проекта

1. Проверьте значения в `scripts/.env`, прежде всего `TEAM_ID`.
2. Сгенерируйте локализации и Xcode-проект:

   ```sh
   make generate
   ```

3. Откройте `BoxingTimer.xcodeproj` и запустите схему `Main` на iPhone, iPad или соответствующем симуляторе. Для Mac выберите `My Mac (Mac Catalyst)`.

Файл проекта генерируется и не хранится в Git. Источником настроек служат `scripts/xcodegen/project.yml` и `scripts/xcodegen/Application.yml`.

## Тесты

После генерации проекта тесты можно запустить в Xcode (`Product` → `Test`) или из терминала:

```sh
make test
```

`make test` автоматически выбирает доступный iPhone Simulator. Для явного выбора задайте `CI_XCODE_DESTINATION`.

Для остальных локальных операций используйте `make lint`, `make build`, `make sounds` и `make bootstrap`.

## Архитектура

```text
Main/App/               сборка зависимостей и точка входа
Main/Core/              движок сессии, расчёт границ и времени
Main/Flows/             экраны настройки и активного таймера
Main/Infrastructure/    аудио, уведомления, хранение и системные сервисы
Main/Model/             доменные модели
Main/Resources/         локализации, ассеты, звуки и plist
Main/UnitTests/         модульные тесты
LiveActivity/           WidgetKit extension, клиент Live Activity и объявленные App Intents
scripts/                генерация проекта, ресурсов и доставка
docs/                   продуктовая и UX-документация
```

`SessionEngine` — источник истины для переходов между подготовкой, раундом и отдыхом. UI-тикер только обновляет представление: после фонового режима состояние пересчитывается по сохранённым датам. Для фоновых сигналов заранее планируются локальные уведомления.

## Ограничения

- Silent Mode, Focus, телефонные звонки и настройки уведомлений могут заглушить фоновые сигналы.
- Live Activity без push-обновлений актуальна только до ближайшей границы этапа; затем она показывает состояние устаревших данных. В текущем UI нет интерактивных действий или кнопки открытия приложения.
- В репозитории пока используются звуки-заглушки из `Main/Resources/Audio`.
- История тренировок, пресеты, Apple Watch, iCloud и аккаунты не входят в текущую версию.
